The frozen offline AI engine is placed here by:  python app/engine/build_engine.py

Contents after build: frameforge-engine.exe, _internal/ (Python runtime, torch, tabpfn)
and models/tabpfn-v2-regressor.ckpt.

If this folder is empty, FrameForge still works using its built-in "Basic tuner"
(usually needs a few more tests to reach the same result).
